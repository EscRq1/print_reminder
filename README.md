# print_reminder
Use -h or --help to see the list of arguments <br />
Use --mark-printed to set up the current date as the last printing date<br />
Use --status to see info about the time and dates<br />
Use --config <Path> to specify the path to the config.json file<br />
Use --set-interval <Number> to set the interval for the reminders(takes only positive numbers)<br />
